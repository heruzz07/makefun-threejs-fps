DUSTLINE — a round-based tactical FPS in an abandoned solar-array yard at desert dusk. Four versus four against bots, first to five rounds: plant the spike or stop it. Economy and buy menu (six weapons including the Longshot DMR, frag and smoke grenades, Kevlar armor), hitscan gunplay with headshots, recoil and spread, and bots that route, hold, peek, retreat and lob grenades. Two mid connectors (the open Connector and the walled Vent corridor), Site A solar rows and Site B pump machinery, gradient dusk sky with drifting clouds.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080 in a desktop browser with WebGL 2
```
